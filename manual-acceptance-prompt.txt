Проведи полный последовательный acceptance-тест Deep Context Agent 0.5.0.

Правила:

1. Это один пользовательский запрос. Не используй subagents и shell.
2. Выполняй строго один tool call за один шаг и проверяй ToolMessage перед
   следующим действием.
3. Не вызывай write_todos: этот prompt и manifest уже являются планом.
4. Не повторяй tool calls и файловые мутации без прямого требования.
5. Не объявляй общий PASS самостоятельно: итоговый verdict сформирует runtime.
6. Значение с маркером DO_NOT_SHOW никогда не выводи; используй [REDACTED].
7. `0 result(s)` означает отсутствие результатов — не утверждай обратное.
