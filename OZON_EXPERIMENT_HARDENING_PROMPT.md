# Промпт исправления Ozon-эксперимента 0.8.3

Устрани три подтверждённые проблемы Deep Context Agent, проявившиеся при
анализе `ozon_market_analytics` 2026-08-23.

1. Упоминание виртуального корня `/workspace/` означает область проекта, а не
   точный файл. Оно не должно блокировать чтение найденных дочерних файлов.
   Явно названный конкретный файл по-прежнему ограничивает exact-read этим
   файлом, а выход за workspace остаётся запрещён.
2. Потоковый индексатор обязан до обхода отсекать generated/cache/coverage и
   browser-profile каталоги и файлы, включая `.pytest-*`, `.coverage*`,
   Playwright-отчёты и `edge-profile*`. Сопоставление служебных имён должно быть
   регистронезависимым. Исходники и проектная конфигурация индексируются.
3. `list_context_sources` по умолчанию возвращает не более 20 источников, а
   запрошенный размер страницы жёстко ограничивается 50. Рабочий промпт Ozon
   должен выполнять один узкий цикл, исправлять один доказанный дефект,
   запрещать широкий glob, повторные calls и более 15 функциональных calls.
4. Распознавай BOM до binary/NUL-проверки, чтобы потоково индексировать
   UTF-16LE/BE и UTF-32LE/BE отчёты. NUL без известного BOM остаётся binary.
5. Программно соблюдай явные total/per-tool budgets из русского и английского
   prose. Exhausted tool скрывай до model-call; stale provider-call не должен
   исполняться или создавать лишнее audit-событие.
6. При пустом toolset не отправляй OpenAI параметры `parallel_tool_calls` и
   `tool_choice`; запрос должен завершаться обычным финальным model response.
7. Располагай budget/exact middleware до sequential normalizer: последний
   обязан видеть окончательный toolset непосредственно перед model handler.
8. Budget parser связывает лимит и tool через обычный перенос строки внутри
   одного пункта, но не через границу предложения.

Добавь regression-тесты для каждого пункта. Обнови системный промпт, ТЗ,
управляющий промпт, README, changelog, статус и версию. Выполни Ruff, полный
pytest, сборку/установку, `pip check`, CLI/doctor и разрешённые OpenAI live
smoke-тесты. При любом сбое исправь код и повтори проверку. После полного PASS
опубликуй версию 0.8.3, затем повтори Ozon-эксперимент на отдельной копии с
новыми `AGENT_WORKSPACE`, `AGENT_DATA_DIR`, thread ID и пустой SQLite-БД.
