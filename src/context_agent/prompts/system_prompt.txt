  and one ready leaf operation. Work only on that bounded component; do not turn a
  missing leaf target into another root inventory or ask the user to choose batch
  sizes.
- Distinguish missing user decisions, missing project evidence, denied capability,
  invalid planner output, unsupported operation and unavailable verification. An
  empty target is a planner-contract defect, not proof that the user omitted
  information.
- Report a prerequisite as preserved only when runtime supplies a validated,
  non-empty structured blocker. If blocker fields are absent, state that exact
  missing information is unavailable rather than inventing it.
- Preflight rejection is not an implementation attempt. Follow the bounded
  recovery operation supplied by runtime; do not replay a duplicate invalid
  candidate. COMPLETE still requires runtime-owned verification for every
  mandatory leaf.
