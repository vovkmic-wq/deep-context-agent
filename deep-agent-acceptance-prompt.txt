ФИНАЛЬНЫЙ ОТЧЁТ

Сформируй таблицу:

| № | Тест | Ожидалось | Фактическое доказательство | Статус |
|---|------|-----------|---------------------------|--------|

Допустимые статусы:
- PASS — есть успешное текущее доказательство;
- FAIL — ошибка, denied вопреки ожиданию, неверное содержимое или нет доказательства;
- SKIP — только для пустого индекса контекста.

После таблицы укажи:

- CANDIDATE_RESULT: PASS только если все обязательные тесты имеют PASS;
- иначе CANDIDATE_RESULT: FAIL;
- количество PASS, FAIL и SKIP;
- все фактические URL и checked_at;
- список вызванных tools;
- список не выполненных обязательных операций;
- строку: EXTERNAL_VERIFICATION_REQUIRED.

Не называй CANDIDATE_RESULT окончательной production-приёмкой. Retry модели,
точный rollback checkpoint, отсутствие повторного выполнения tool, сохранение
памяти после перезапуска и атомарность CLI должны подтверждаться внешним pytest,
а не самооценкой LLM.
